## Step 1: Export Data from LinkedIn Analytics

For each data source, navigate to LinkedIn's analytics pages, export the data and add it to the corresponding Google Sheet:

| Data Source | LinkedIn Path               | Sheet Name     | Format        |
|-------------|------------------------------|----------------|---------------|
| Analytics   | Analytics > Overview          | Summary Sheet  | CSV/Excel     |
| Ads         | Analytics > Ads              | Ads Data       | CSV/Excel     |
| Engagement  | Analytics > Engagement        | Engagement Data | CSV/Excel     |
| Newsletter   | Analytics > Newsletters      | Design Feast    | CSV/Excel     |
